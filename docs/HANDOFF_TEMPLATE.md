# Project handoff

- Progress: completed work and remaining decisions.
- Outputs: exact artifact paths and verification evidence.
- Required worktrees: path, branch/commit, owner, reason still needed.
- Next step: the next concrete action and any pending approval.

Update the project's existing handoff file. If it has none, use a project-named
file in `CODEX_HOME/maintenance/handovers`. Keep machine-local paths and private
evidence there rather than committing them into this portable repository.
